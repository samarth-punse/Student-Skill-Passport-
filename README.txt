SKILLPASSPORT FRONTEND PROTOTYPE

Pages: index.html (login), dashboard.html (student dashboard), profile.html (SkillPassport profile).

Run: Extract the ZIP, then open index.html in a browser. Use any valid-looking email and a password of 4+ characters. Submit to reach the demo dashboard. Navigate with sidebar links.

This is frontend-only. No backend, database, real authentication, real verification, or real file upload is connected. All profile data and badges are illustrative demo data.
